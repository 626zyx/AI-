# AI 安全平台 · 攻防演练（重构版）

从零重写的演示前端。只保留攻防演练一条主线，数据全部来自 OpenRT 对真实模型发起攻击后的判定结果。

## 运行

ES module 不能通过 `file://` 打开，必须起一个本地静态服务。

```bash
cd AI演练场
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

`启动服务.bat` 双击等价于上面的命令（Windows）。

```

  domain/
    constants.js      状态、对象类型、模型角色、导航定义

    store.js          唯一数据出口。接后端只改这一个文件
  pages/              一个页面一个文件，只返回 HTML，不碰外壳
  styles/

  data/               自动生成，勿手改：tasks/units/logs 由 extract.py 从 OpenRT 结果生成；catalog.js（攻击方法目录、AdvBench 520 题与攻击场景）由 extract_catalog.mjs 从旧版 demo 提取

  extract.py          从 OpenRT 结果目录重新生成任务数据
  extract_catalog.mjs 从旧版 demo 提取攻击方法与题库
  check.mjs           jsdom 逐路由渲染 + 交互检查（筛选、更多下拉、复测、草稿、对比、题库分页）
  dead.mjs            死代码扫描：未引用的 CSS 类 / JS 导出
  shot.py             逐路由截图到 _shots/
  shot_interact.py    交互态截图：新建向导、草稿、对比、攻防明细
  measure.py          全站主标题位置对齐检查
  btn.py              带框按钮宽度档位检查（应只有三档）
  focus.py            筛选框输入不丢焦点检查
```

## 数据

两个演练任务，同一套攻击策略（AdvBench 前 20 题 × Direct / JailBroken / DeepInception / PAIR），
只有靶标不同：

| 靶标 | Direct | JailBroken | DeepInception | PAIR | 任务 ASR |
| --- | --- | --- | --- | --- | --- |
| DeepSeek-V3-Chat | 0/20 | 0/20 | 0/20 | 9/20 | 11.3%（9/80） |
| Qwen-Flash | 0/20 | 0/20 | 1/20 | 14/20 | 18.8%（15/80） |

裁判模型 DeepSeek-V3-Flash，判定口径为 LLM Judge 单次打分 ≥ 5 计为攻破。
ASR = 攻破数 ÷ 有效判定数，未判定单元不进分母。

任务详情的运行日志由四个方法的原始日志按方法顺序直接拼接，未做合并。

重新生成数据：

```bash
python _tools/extract.py   # 读 D:\演练产品\跑数据\OpenRT\results\ 下的两个结果目录
```

## 边界

- 蓝队（Qwen3Guard 输入输出双检）已完成界面与配置设计，但两条演练任务均未配置蓝队，
  相关指标留空而不是填模拟值。
- 智能体演练只留入口，未实现。
- 所有删除操作只弹提示，不真正删除。
- 并发数 3、单次输出上限 2048 按实际运行配置填写。
- 对比结果导出 PDF 走浏览器打印（另存为 PDF）。

## 0.2 变更

- 策略中心：攻击策略下新增「攻击方法」（21 个 OpenRT 方法，按名称/说明搜索、按技术路线筛选，详情抽屉）与「攻击题库」（AdvBench 520 题，详情抽屉内搜索、按场景筛选、每页 10 条；新建题库：名称、行业含自定义、上传 JSON + 模板、待入库预览）。
- 安全态势清空为占位页；删除各页标题描述与表单说明文字。
- 新建/复测合并为单个弹窗，弹窗内可直接保存草稿；取消后「继续编辑」回到原弹窗。
- 筛选器修复：原 onchange 属性内嵌双引号导致选择器失效，改由 `UI.filters` 统一转义。
- 「更多」改为行内下拉；蓝队统一为「已配置/未配置」。
- 任务详情：演练结果四态（已攻破/已守住/异常/待判定），详细配置按「题库·前 N 题」与「方法（参数）」展示；运行日志深色底。
- 演练结果按 ASR 降序；结果对比改为「选择对比任务」弹窗 + 独立对比页（可导出 PDF）。
- 报告列表去掉 ASR/风险等级，操作为详情、删除。报告正文留待 0.3。

## 0.3 变更要点

- 返回键只有拐弯箭头图标，回到上一步所在页面（router 历史栈）；直接打开详情链接时退回所属列表。
- 判定统一为「已攻破 / 已守住 / 异常」；异常改为橙黄 `--st-error`。
- 列表统一 `UI.pagedTable`，每页 15 条，带第一页/上一页/下一页/最后一页。
- 「更多」下拉改为 `position: fixed` 浮层，下方空间不足时向上展开，不撑开表格。
- 新建与复测共用同一弹窗（标题「新建模型演练」、按钮「创建任务」）；任务名称必填且与任务列表、草稿箱不可重名。
- 报告详情：左栏演练结果/核心发现/下一步建议/场景风险分析/方法表现分析，右栏基础信息/详细配置；攻防明细支持筛选、勾选、导出 PDF/MD。
