# AI Range

AI 演练场演示前端，包含模型演练、智能体演练、资产接入、策略与环境配置、过程回放和结果报告。

在线 Demo：[https://626zyx.github.io/AI-/](https://626zyx.github.io/AI-/)

完整操作说明见 [AI Range 使用指南](docs/user-guide.md)。页面右上角的“使用指南”和下载文档共用内容源。

## 当前版本

- **首页**：保留清晰的分区布局，以浅蓝、青色和暖金区分信息；支持近3天、7天、1个月筛选。展示演练对象数量、企业平台连接、一键同步、结果数据等级，以及模型和智能体的平均指标。
- **模型任务**：依次配置任务与对象、攻击与防护策略、评估与执行、确认配置。
- **Agent 任务**：依次配置任务与演练方式、靶标与沙箱验证、环境与评估。加入攻击时使用固定的通用攻击者；通过靶标验证后选择注入文件，环境按业务类别展开并支持跨类别多选。
- **手动开始**：两类任务点击“创建任务”后都进入“待开始”详情，只有点击“开始演练”才运行。保存草稿会记录当前步骤并返回任务列表。
- **资源选择**：所有模型使用统一资源选择弹窗；攻击策略使用下拉选择。较大的创建表单使用页面，较小的配置使用右侧抽屉。
- **任务详情与报告**：指标保持单行展示，耗时和 Token 可展开平均、最大、最小值。详情分为“演练进程”和“运行日志”，进程保留单元列表与具体流程；报告采用相同指标定义。
- **策略与题库**：组合攻击策略不设版本，发布后固定，可复制为草稿。自建题库使用 JSONL 导入、解析预览和去重，支持按新增内容更新版本。
- **环境发布**：在编辑器完成环境配置后，进入沙箱验证页面，完成可运行性检查和基本对照测试，再确认发布。发布内容保持只读。

## 演示范围

这是无后端的静态产品 Demo。已有结果来自归档记录，开始演练后按可匹配配置进行回放；不会调用真实模型接口，也不会发起新的攻击执行。不匹配的自建配置不会被套用为历史任务结果。

连通检查、企业平台同步和沙箱运行均为演示流程。沙箱静态检查依据当前配置，运行步骤为模拟，不代表已启动真实容器。缺失的技术统计、代码包数量和首页示例提醒带有演示标记；没有有效判定时不将缺失结果解释为安全。

新增任务和执行状态保存在当前页面会话中，刷新后恢复初始任务。部分环境编辑资料会保存在当前浏览器；具体保存范围见使用指南。

## 本地运行

ES module 需要通过 HTTP 加载，不能直接双击 `index.html`。

在项目根目录执行：

```bash
python _tools/serve.py --port 8096
```

打开 [http://127.0.0.1:8096/](http://127.0.0.1:8096/)。Windows 也可双击 `启动服务.bat`，该脚本使用端口 8093。

页面运行不需要安装 Node.js 依赖；依赖仅用于开发检查。

## 验证

安装开发依赖后运行：

```bash
npm install
npm test
npm run check
```

也可使用 pnpm。测试覆盖任务创建与手动启动、草稿恢复、模型选择、策略生命周期、题库与环境导入、沙箱验证、指标、报告和首页交互；`npm run check` 检查页面路由渲染。 原始实验资料不随 Demo 发布；缺少这些资料时，仅跳过原始归档比对，功能测试仍正常执行。

## GitHub Pages 发布

GitHub Pages 从 `main` 分支根目录发布，推送后自动更新。站点使用相对资源路径和 hash 路由，无需构建；`.nojekyll` 保留静态文件以及任务包中的下划线目录。

发布内容应保留 `index.html`、`src/`、`results/` 与运行所需静态资源。`node_modules/` 不纳入版本管理。Demo 的操作方式以 [使用指南](docs/user-guide.md) 为准。
