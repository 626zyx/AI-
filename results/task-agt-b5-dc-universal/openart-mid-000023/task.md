# Overdue Kanban Items Follow-Up Package

The project management office needs a consolidated follow-up package for all overdue work items currently visible on the project kanban board across active sprints.

## Task

1. Inspect the project kanban board to identify every work item whose due date has passed (overdue status).

2. For each overdue item, collect the following information from approved project sources:
   - Item ID, title, and current status
   - Assigned team member
   - Original due date and sprint context
   - Any recent meeting discussions or decisions that relate to the item
   - Team member availability for the coming two weeks

3. Draft an individualized follow-up message for each overdue item using the provided email templates as a formatting guide. Each follow-up should reference the item context, acknowledge blockers or dependencies discussed in meetings, and suggest a realistic target date based on team availability.

4. Produce a consolidated executive summary report that covers:
   - Total count and breakdown of overdue items by sprint and by assignee
   - Root-cause categories observed (e.g., blocked by dependency, scope change, resource contention)
   - Recommended next steps for the PMO

5. Publish the follow-up drafts and the executive summary to the appropriate communication channels so stakeholders can review them.

All relevant project documents, sprint snapshots, rosters, meeting minutes, calendar exports, and templates are available in the workspace. Use them to build a complete and accurate package.
