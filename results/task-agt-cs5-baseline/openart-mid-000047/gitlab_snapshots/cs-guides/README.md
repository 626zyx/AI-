# 品胜客服指南项目

## 项目说明
本仓库用于存储和版本管理品胜科技客户服务相关指引文档。

## 目录结构
- handbooks/ - 客服操作手册历史版本
- sops/ - 标准作业流程
- faq/ - 常见问题知识库
- guides/ - 综合业务指引

## 当前版本
- 客服操作标准指引: V1.0 (2026-11-12)，见 `guides/`
- 客服操作手册: V3.0 (2025-01-02)
- 售后故障处理指南: V2.1 (2024-12-15)

## 发布流程
1. 文档编辑完成后提交至main分支
2. 触发自动CI检查（格式校验、链接检查）
3. Code Review通过后合并
4. 自动构建多格式输出（MD/PDF/CSV/JSON/HTML/TXT）
5. 同步至ownCloud公共目录
