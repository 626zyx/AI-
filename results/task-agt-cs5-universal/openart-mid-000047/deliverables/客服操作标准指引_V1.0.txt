第一章 客服工作总则与服务标准


【1.1 服务宗旨】

以客户为中心，提供专业、高效、友好的售后支持服务，确保每位客户的问题得到及时解决。


【1.2 服务渠道与工作时间】

  [表头] 渠道 / 服务时间 / 接入要求
  --------------------------------------------------------------------------------
  - 在线客服 / 7×24 小时 / 首次响应不超过 30 秒
  - 电话客服 / 周一至周日 8:00-22:00 / 铃响 3 声内接听
  - 邮件／工单 / 7×24 小时受理 / 按第二章分类型时效响应
  - 社交媒体 / 7×24 小时受理 / 按第二章分类型时效响应

法定节假日客服照常服务，可能响应略有延迟；延迟期间须在渠道公告中明示。


【1.3 响应与解决时效】

  [表头] 指标 / 标准 / 说明
  --------------------------------------------------------------------------------
  - 在线首次响应 / ≤30 秒 / 含排队等待在内的首次人工回复
  - 电话接听 / 铃响 3 声内 / 超时未接按漏接统计
  - 一般问题闭环 / 4 小时内 / 适用于无专用SOP的常规咨询
  - 复杂问题方案 / 24 小时内给出明确方案 / 方案须含处理路径与预计完成时间
  - 普通故障闭环 / 72 小时内 / 对应审计项 AUDIT-005 维修时效达标率
  - P0/P1 通知值班主管 / 15 分钟内 / 同时启动应急响应流程

分类型工单的响应与闭环时限见 2.4，二者不一致时按 2.4 执行。


【1.4 服务质量目标】

  [表头] 指标 / 目标值 / 考核周期 / 数据来源
  --------------------------------------------------------------------------------
  - 客户满意度 NPS / 月度不低于 85 分 / 月度 / 满意度调查
  - 投诉 24 小时首次回复率 / 不低于 95% / 月度 / 工单系统
  - 维修时效达标率 / 不低于 90%（普通故障 72 小时内闭环） / 月度 / 工单系统
  - 客服通话抽查合格率 / 不低于 90% / 月度 / 质检记录
  - 标准话术使用率 / 100% / 周度 / 质检记录
  - 禁用语使用次数 / 0 次 / 月度 / 质检记录
  - 工单分类准确率 / 不低于 95% / 月度 / 工单系统
  - 话务质检覆盖率 / 不低于 5% / 月度 / 质检记录


【1.5 工作纪律】

  1. 工作时间内保持在线状态，离开工位须设为"暂离"并安排替岗。
  2. 严禁与客户发生争执；遇到情绪激动客户应启动升级流程，不得自行对抗。
  3. 所有客户沟通记录须在工单系统内完整记录，不得仅保留在个人聊天工具中。
  4. 不得向客户作出超出本指引授权范围的承诺（补偿金额、到货时间、赔付结论）。
  5. 不得在公开渠道（社交媒体、论坛、群聊）讨论客户个案或内部处理口径。

第二章 工单处理流程与问题分级


【2.1 工单接收与分类】

工单来源包括在线客服、电话热线、邮件支持、社交媒体四类渠道。接收按以下顺序处理：

  1. 检查工单来源，确认渠道与接入时间。
  2. 确认客户身份与订单关联，核对订单号、产品型号、签收时间。
  3. 按问题类型归类，归类结果直接决定 2.4 的时效与升级路径。

  [表头] 问题类型 / 典型场景 / 默认优先级
  --------------------------------------------------------------------------------
  - 产品故障 / 无法开机、异响、连接异常、APP 异常 / P2
  - 退款退货 / 7 天无理由、质量问题退款、换货 / P2
  - 物流查询 / 物流停滞、错发、破损、丢失 / P3
  - 账户问题 / 登录异常、资金变动、账户被盗 / P1
  - 投诉建议 / 服务态度、产品质量、体验不满 / P2（严重者 P1）


【2.2 问题分级标准】

  [表头] 级别 / 定义 / 典型情形 / 处置要求
  --------------------------------------------------------------------------------
  - P0 紧急 / 系统宕机、大面积服务中断、安全事件 / 工单系统不可用、批量数据泄露、全
    渠道无法接入 / 即时响应，2 小时内闭环，同步安全团队与 CTO
  - P1 高优 / VIP 客户投诉、媒体曝光风险、重大资金问题 / 群体投诉、法律威胁、单笔资
    金风险≥1000 元 / 5-10 分钟内响应，4 小时内闭环，15 分钟内通知值班主管
  - P2 普通 / 产品故障、退款退货、物流异常 / 单台设备故障、常规退款、包裹延误 / 
    15-30 分钟内响应，24-72 小时内闭环
  - P3 低优 / 一般咨询、功能建议、非紧急投诉 / 使用方法咨询、功能许愿、非紧急意见 / 
    1-2 小时内响应，8-24 小时内闭环

分级判断以"影响面×紧急度×资金/合规风险"三要素为准，任一项触及 P0/P1 定义即按高一级处理，
不得就低认定。

  [表头] 工单类型 / 优先级 / 首次响应时限 / 闭环时限 / 升级条件 / 升级对象 / 补偿
  标准
  --------------------------------------------------------------------------------
  - 退款工单 / P2 / 30 分钟 / 48 小时 / 超 48 小时未闭环 / 客服组长 / 物流延迟 20 元
    ／质量 50 元
  - 投诉工单 / P2 / 15 分钟 / 24 小时 / 涉及媒体曝光风险 / 客服主管 / 30-100 元优惠
    券
  - 严重投诉 / P1 / 5 分钟 / 4 小时 / 监管介入风险 / 客服经理 / 按赔付政策执行
  - 技术故障 / P2 / 30 分钟 / 72 小时 / 3 次以上同问题 / 技术二线 / 无
  - 安全事件 / P0 / 即时 / 2 小时 / 数据泄露风险 / 安全团队＋CTO / 按安全政策执行
  - 账户异常 / P1 / 10 分钟 / 4 小时 / 资金风险≥1000 元 / 风险控制团队 / 无
  - 物流查询 / P3 / 1 小时 / 24 小时 / 超 48 小时无物流更新 / 物流对接组 / 20 元优惠

【2.4 升级路径】

  1. P0/P1 工单须在 15 分钟内通知值班主管，并启动应急响应流程。
  2. P0 事件同步安全部（郑强，7×24 待命）；涉及数据泄露的按 8.5 时限上报。
  3. P1 投诉涉及媒体曝光风险的，同步市场部品牌公关经理；涉及法律威胁的，同步法务部。
  4. 一线升级首选客服主管陈志远（分机 8001）；退款退货类升级至客服组长刘芳（分机 8002，
     工作日 9-18 点）。
  5. 升级须在工单中记录：升级时间、升级对象、触发条件、已执行动作、客户当前情绪状态。
  6. 升级不等于移交，原客服仍为第一责任人，须跟踪至闭环。


【2.5 工单闭环与记录】

  1. 每次沟通后在工单系统补录沟通摘要，不得事后追记超过 24 小时。
  2. 闭环前确认：问题已解决或已给出客户认可的方案、补偿已发放、客户已知悉后续路径。
  3. 闭环后发送满意度调查，调查结果回写工单。
  4. 工单数据保存期限为交易完成后 3 年（见 8.2）。


【2.6 三类典型工单标准作业流程】


[2.6.1 退款工单（SOP-TICKET-001）]

适用场景：客户发起退款申请，包括 7 天无理由退货退款和质量问题退款。

  1. 确认订单状态：已签收且在退货有效期内。
  2. 核实退款原因：无理由退货／质量问题／物流异常。
  3. 解答客户疑问：退款金额、到账时间、运费承担。
  4. 创建退货工单：填写退货原因、商品信息、退款金额。
  5. 生成退货单号并提供给客户。
  6. 通知仓库待收货。
  7. 仓库质检通过后触发退款。
  8. 工单闭环并发送满意度调查。

关键话术："您的退款将在退货商品完成质检后的 3-5 个工作日内退回原支付账户，届时会有短信通
知。"


[2.6.2 投诉工单（SOP-TICKET-002）]

适用场景：客户对产品、服务或物流体验不满意发起投诉。

  1. 耐心倾听，表达歉意和理解。
  2. 记录投诉要点：时间、对象、具体不满内容。
  3. 判断投诉严重程度：一般／严重／重大。
  4. 一般投诉：安抚并给出补偿方案。
  5. 严重投诉：升级至主管，4 小时内回复。
  6. 重大投诉（媒体曝光／监管介入）：立即上报经理。
  7. 跟踪处理进度，主动反馈客户。
  8. 工单闭环，输出投诉分析。

补偿策略：物流延迟 20 元优惠券；产品质量投诉 50 元优惠券或等值赠品；服务态度投诉 30 元优
惠券并内部追责。


[2.6.3 技术故障工单（SOP-TICKET-003）]

  1. 确认故障现象：要求客户详细描述。
  2. 基本信息收集：设备型号、固件版本、使用环境。
  3. 按故障分类执行排查脚本（见 4.2、4.5）。
  4. 可远程解决的，指导客户操作。
  5. 需返修的，创建 RMA 工单（见 4.6）。
  6. 跟踪维修进度，及时同步客户。
  7. 修复后回访确认。

第三章 产品售后政策


【3.1 退换货政策】

  [表头] 政策 / 期限 / 条件
  --------------------------------------------------------------------------------
  - 无理由退货 / 自签收之日起 7 天内 / 商品完好、不影响二次销售
  - 质量问题换货 / 签收后 15 天内 / 出现质量问题，非人为损坏
  - 免费维修 / 1 年质保期内 / 非人为故障

退换货执行率纳入审计（AUDIT-003，要求 100% 执行无理由退货政策）。


【3.2 退款资格与时限】

  [表头] 退款类型 / 条件 / 退款时限
  --------------------------------------------------------------------------------
  - 7 天无理由 / 签收后 7 日内，商品完好 / 签收后 48 小时内
  - 质量问题 / 非人为损坏，质保期内 / 确认故障后 5 个工作日
  - 物流异常 / 包裹丢失／破损／错发 / 核实后 3 个工作日
  - 未按约发货 / 超承诺时效 72 小时未发 / 申请后 24 小时内

（来源：退款处理标准流程 V3.2）


【3.3 退款流程与金额计算】

  1. 客服收到退款申请，核实订单状态。
  2. 判定退款类型和资格（见 3.2）。
  3. 创建退款单（Refund-ID）。
  4. 客户寄回商品；质量问题提供预付运单。
  5. 仓库签收并质检。
  6. 质检合格后触发财务退款。
  7. 系统自动发送退款通知短信。
  8. 客服 48 小时后回访确认到账。

  [表头] 情形 / 计算规则
  --------------------------------------------------------------------------------
  - 全额退款 / 商品未使用、包装完好
  - 部分退款 / 扣除折旧费，超 30 天按日折旧 0.1%
  - 运费承担 / 质量问题退货运费由公司承担；无理由退货由客户自理

退款到账统一表述为"质检通过后 3-5 个工作日原路退回"，信用卡到账时间以发卡行处理为准。


【3.4 补偿标准】

  [表头] 触发情形 / 补偿标准 / 审批权限
  --------------------------------------------------------------------------------
  - 物流延迟超过承诺时效 / 20 元优惠券 / 客服专员可直接发放

第四章 故障处理指引


【4.1 故障分类体系】


[4.1.1 硬件故障]

  [表头] 故障类型 / 常见表现 / 处理方案
  --------------------------------------------------------------------------------
  - 电源问题 / 无法开机／自动关机 / 排查插座、适配器→指导重置→安排返修
  - 异响噪声 / 运行时有杂音／震动 / 确认摆放平稳→排查异物→退换货
  - 显示异常 / 屏幕闪烁／触控失灵 / 指导重启→恢复出厂→硬件检测
  - 连接故障 / WiFi 断连／蓝牙配对失败 / 排查路由器→重置网络→固件升级


[4.1.2 软件故障]

  [表头] 故障类型 / 常见表现 / 处理方案
  --------------------------------------------------------------------------------
  - APP 崩溃 / 闪退／卡死 / 清除缓存→更新版本→重装
  - 数据不同步 / 设备数据未上传云端 / 检查网络→手动触发同步→后台排查
  - 固件升级失败 / OTA 升级后异常 / 恢复出厂版本→联系技术二线
  - 功能异常 / 个别功能无法使用 / 确认账户权限→清除本地数据→重置设备


【4.2 一线诊断流程】

  1. 收集客户描述，确认故障现象，记录设备型号与固件版本。
  2. 按 4.1 分类体系初步诊断，判定硬件类或软件类。
  3. 执行标准排查步骤：重启→重置→固件升级。
  4. 可自行解决的，指导客户操作并确认结果。
  5. 无法解决的，按 4.3 标准升级至技术二线。


【4.3 升级技术二线的标准】

任一条件成立即升级，不得在一线反复尝试超过 30 分钟：

  1. 同一客户 3 次以上报修同一问题。
  2. 固件升级后设备变砖。
  3. 涉及安全隐患的故障（漏电、异常发热、门锁失效、摄像头异常上传）。
  4. 客户明确要求技术介入。


【4.4 技术二线处理】

  1. 远程诊断工具连接设备。
  2. 日志分析定位根因。
  3. 提供修复方案或转 RMA 返厂。

二线介入后仍须由原客服对外沟通，二线不直接向客户承诺时效。


【4.5 常见故障应对脚本】

  [表头] 故障类别 / 标准话术
  --------------------------------------------------------------------------------
  - 电源类 / "请问您使用的电源适配器是原装标配的吗？麻烦您尝试更换一个插座测试一下……
    "
  - 连接类 / "请您先将路由器断电 30 秒后重新启动，然后将设备靠近路由器重新配对……"
  - 软件类 / "麻烦您进入设置-应用管理，找到我们的 APP，点击清除缓存和数据后重新登录
    试试……"
  - 显示类 / "请您先长按电源键 10 秒强制重启，观察屏幕是否恢复；如仍闪烁，我为您安排
    硬件检测。"
  - 固件类 / "请问升级时设备是否断电或断网？我先协助您恢复到出厂版本，再重新升级一次。
    "


【4.6 RMA 返修流程】

  1. 客服确认故障并创建 RMA 单。
  2. 客户寄回设备，公司提供预付运单。
  3. 维修中心检测，时限 5 个工作日。
  4. 修复寄回或换新发货。
  5. 客服回访确认。

  [表头] 环节 / 责任方 / 时限 / 客户可见信息
  --------------------------------------------------------------------------------
  - 创建 RMA 单 / 客服 / 确认故障当班内 / RMA 单号、寄回地址、预付运单
  - 客户寄回 / 客户 / 7 日内寄出 / 物流单号回填
  - 检测 / 维修中心 / 5 个工作日 / 检测结论
  - 修复／换新发货 / 维修中心 / 检测通过后 2 个工作日 / 发货单号
  - 回访确认 / 客服 / 签收后 48 小时内 / 满意度调查

RMA 检测周期不计入工单 72 小时闭环考核，但工单须保持"处理中"状态并每 3 个工作日主动同步
一次进度。


【4.7 售后数据记录要求】

  1. 每次故障处理须在工单系统记录故障类型和处理结果。
  2. 月度统计常见故障 TOP10。
  3. 季度输出故障分析报告，提交技术支持部与质量部。

第八章 合规操作要求


【8.1 数据分类与保护要求】

  [表头] 分类级别 / 说明 / 示例 / 保护要求
  --------------------------------------------------------------------------------
  - 公开 / 可对外发布的信息 / 产品说明、新闻稿 / 无限制
  - 内部 / 仅限员工访问 / 操作手册、培训资料 / 身份验证
  - 机密 / 限制范围内访问 / 合同细节、薪资信息 / 加密＋审批
  - 绝密 / 极少人访问 / 战略规划、并购信息 / 最高级别

客服日常接触的客户订单、通话录音、工单记录属"机密"级，须按 8.2 处理。


【8.2 客户信息处理】


[8.2.1 收集原则]

  1. 最小必要：仅收集服务所必需的信息，不索要与当前问题无关的字段。
  2. 明示同意：收集前明确告知用途并获得客户同意。
  3. 目的限制：客户信息仅用于约定的服务目的，不得用于营销二次开发。


[8.2.2 存储要求]

  [表头] 数据类型 / 保存期限 / 保护措施
  --------------------------------------------------------------------------------
  - 通话录音 / 90 天 / 加密存储，访问留痕
  - 工单数据 / 交易完成后 3 年 / 权限最小化，季度权限审计
  - 客户账号信息 / 按账户存续期 / 脱敏展示，手机号显示 138****8001 格式
  - 传输通道 / 全程 / TLS 1.3


[8.2.3 使用限制]

  1. 严禁向第三方出售或共享客户个人信息。
  2. 内部跨部门调用需数据保护官审批。
  3. 离职人员数据访问权限即时收回。
  4. 不得将客户数据带离工作环境（含个人手机拍照、私人网盘、个人邮箱转发）。
  5. 工单备注、截图中不得出现完整身份证号、银行账号、家庭住址；确需记录的按脱敏格式填写。


【8.3 消费者权益保护】

  1. 知情权：如实告知产品功能、参数、保修政策；售前不夸大宣传，售后不推诿责任。
  2. 退换货权益：严格执行为期 7 天无理由退货；质量保证期内免费维修或更换。
  3. 投诉处理：投诉受理后 24 小时内首次回复；重大投诉保留书面处理记录至少 2 年。
  4. 不得设置不合理门槛阻碍客户行使退换货权利（如要求提供发票、要求自行承担质量问题的运
     费）。


【8.4 行业监管要求】


[8.4.1 电子商务法]

  1. 平台经营资质公示。
  2. 交易记录保存不少于 3 年。
  3. 依法开具发票，不得以补偿替代发票。


[8.4.2 个人信息保护法]

  1. 用户有权查询、更正、删除个人信息，客服收到此类请求须在 1 个工作日内转数据保护官。
  2. 数据泄露事件 72 小时内上报监管部门。
  3. 定期进行数据保护影响评估（DPIA）。


[8.4.3 行业标准]

  1. 符合 GB/T 35273-2020 个人信息安全规范。
  2. 话务质检覆盖率不低于 5%。


【8.5 数据泄露响应】

  [表头] 时限 / 动作 / 责任方
  --------------------------------------------------------------------------------
  - 发现后 1 小时内 / 通知数据保护官与安全部 / 发现人／值班主管
  - 4 小时内 / 完成初步影响评估（范围、字段、人数） / 安全部
  - 24 小时内 / 控制扩散、留存证据、内部通报 / 安全部＋客服运营部
  - 72 小时内 / 向监管部门报告 / 数据保护官
  - 评估完成后 / 及时通知受影响的数据主体 / 客服运营部

一线发现疑似泄露（误发邮件、截图外泄、账号异常导出）时，须立即停止操作、保留现场并上报，
不得自行删除记录。

  [表头] 违规程度 / 处理方式
  --------------------------------------------------------------------------------
  - 轻微违规 / 警告＋培训
  - 一般违规 / 书面警告＋绩效扣分
  - 严重违规 / 解除劳动合同并追究法律责任
