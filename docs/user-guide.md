# AI Range 使用指南

本指南按“准备资产 → 发布策略 → 创建演练 → 查看过程 → 分析结果”的顺序介绍 AI Range，适用于模型演练与 Agent 演练。

1. 平台概览与快速开始
2. 首页与安全态势

## 1. 平台概览与快速开始

### 功能导航
| 入口 | 主要用途 |
|---|---|
| 首页 | 打开初始首页，按引导接入资产并创建任务 |
| AI Range 标题 | 打开已有数据的安全态势，查看演练指标、风险和资产分布 |
| 模型演练 | 创建模型安全任务，查看演练报告与模型评估 |
| Agent 演练 | 创建智能体任务，查看演练报告与 Agent 评估 |
| 策略中心 | 管理策略、攻击方法、攻击题库、场景题库和防护策略 |
| 资产中心 | 接入模型与智能体，查看接入配置和状态 |
| 风险中心 | 筛选风险事件、标记处理状态并发起复测 |

### 首次使用
1. 接入所需模型，在“配置模型用途”中分配靶标、攻击生成、裁判或智能体基座用途。
2. 若测试 Agent，再接入智能体镜像，并核验它的运行能力和注入文件。
3. 在策略中心准备策略，检查方法、参数、辅助模型及题库范围后发布。
4. 新建演练任务，选择靶标、策略和裁判，核对配置后保存。
5. 在任务详情点击“开始演练”，完成后查看报告；按需进入评估或风险中心继续分析。

## 2. 首页与安全态势

### 初始首页
顶栏“首页”进入初始首页（home/home），用于示范全新账号的首次使用状态。点击 AI Range 标题或“查看安全态势”进入已有演练数据页（posture/home）。两页独立展示，打开初始首页不会删除已有资产、任务或演练结果。

初始首页保持顶部安全态势、左侧演练场、右侧风险与资产的布局，演练场与右栏宽度约为 3:2。演练任务、攻击单元、攻破或泄漏、整体 ASR、覆盖靶标、风险事件六项指标均显示“—”，附各自统计口径，等待首次演练产生有效数据。

演练场可切换模型与 Agent 视图，展示通用流程说明，不播放任务数据，也不生成模拟判定。底部通过“接入资产 → 准备策略 → 新建任务”三步引导完成准备。

风险提醒显示“尚未评估”，不代表安全。“我的资产”显示等待接入；系统题库单独展示，只统计和列出系统来源且已有内容的题库目录，不将其算作用户资产。

### 已有数据的安全态势
点击 AI Range 标题进入此页。安全态势、风险提醒和资产态势使用已有演练数据，可切换近 7 天、近 30 天或全部时间范围；不会显示初始页的“等待接入”状态。

演练场与初始首页共用相同的模型／Agent 通用流程动画、3D 场景和颗粒内容流。默认模型视图，点击双向切换图标切换；画布支持缩放和拖动。画板不回放具体任务或生成攻破结论，具体任务状态、日志与证据仍在任务详情查看。

风险提醒列出当前范围内的三条风险，可打开对应任务或进入全部风险。资产态势左侧圆环展示当前范围内已演练资产的模型／智能体分布，右侧列出这些靶标及其任务平均 ASR。任务平均 ASR 为该靶标在当前时间范围内各任务 ASR 的算术平均值，没有有效判定的任务不计入；未产生演练记录的资产不会因此被判定为安全。

Agent 流程示意依次介绍准备题目、布置攻击、靶标执行和裁判评估。评估内容在执行之后介绍，不提前生成评价，也不展示任务实际轨迹。

### 正式接入后的状态规则
| 账号状态 | 展示规则 |
|---|---|
| 已接入资产，尚无演练任务 | 显示已接入资产；评估结果显示“—”，风险为尚未评估 |
| 演练进行中 | 可以展示执行进度；尚未形成有效判定的评估项保持“—” |
| 演练完成且有有效判定 | 按实际证据更新评估指标与风险，不预先生成结论 |
| 没有有效判定 | 对应结果显示“—”，不将缺失结果解释为安全或 0% ASR |

## 3. 接入模型与配置用途

进入“资产中心 → 模型”，点击“接入模型”。

| 字段 | 填写要求 |
|---|---|
| 模型名称 | 平台内用于识别、搜索和筛选的名称 |
| 请求模型标识 | 模型服务实际接受的 model 值，例如 deepseek-chat |
| API 地址 | 服务的 Base URL，例如 https://api.example.com/v1 |
| 接口类型 | 选择服务实际支持的协议 |
| 鉴权方式 | 按服务要求选择 API Key 或无鉴权 |
| API Key | 仅在服务要求鉴权时填写 |

按表单完成连接检查并保存，再点击“配置模型用途”。一个模型可有多种用途；只有配置了对应用途的模型，才会出现在策略或任务的相关选项中。

已被任务、策略或智能体引用的模型，接入参数可能被锁定，以保留历史配置。更换服务或模型版本时应新增资产。

## 4. 接入智能体

### 4.1 接入准备
先接入基座模型，再进入“资产中心 → 智能体 → 接入智能体”。镜像须包含 Agent 程序、依赖与所需工具，已有非交互运行入口，并能在任务结束后退出。新接入镜像必须支持本节“基座模型连接”规定的三个标准环境变量；不支持时，由镜像开发者在交付前完成适配。

用途说明只描述这个 Agent 能做什么，例如“读取业务文档并整理客服回复”。它用于资产识别，不作为演练任务指令。

### 4.2 镜像与启动入口
| 字段 | 填写要求与示例 |
|---|---|
| 智能体名称 | 平台内可区分的名称 |
| 基座模型 | 选择资产中心已接入且具有智能体基座用途的模型 |
| 镜像地址 | 完整 Docker 镜像引用，例如 registry.example.com/team/agent:1.0.0，或 repository@sha256: 后接 64 位摘要 |
| 启动程序 | 一个程序名或容器内路径，例如 agent-cli、/app/run-agent |
| 启动参数 | 每行一个参数或参数值；没有固定选项时留空 |

版本已包含在镜像地址中，无需再填版本。镜像地址不是网页链接或 ZIP/TAR 下载地址。

假设已有入口为 agent-cli --non-interactive --format json，启动程序填 agent-cli，启动参数依次分三行填写：

```text
--non-interactive
--format
json
```

每行作为一个独立参数，行内空格属于该参数值。不写 shell 管道、重定向、任务正文或任务参数名；需要初始化时，由镜像已有入口负责。

### 4.3 任务文本传入方式
平台读取完整 task.md，补充运行及可用工具说明，形成完整任务文本。选择 Agent 已有入口支持的传递方式：

| 方式 | 实际传递内容 | 用户填写 |
|---|---|---|
| 标准输入（stdin） | 完整任务文本通过标准输入送入程序 | 不填任务参数名 |
| 命令行参数（argv） | 完整任务文本作为一个参数值追加 | 填 -p、-n 或 --prompt 等单个参数名；留空表示最后一个位置参数 |
| 通过文件传入任务 | 平台先生成 UTF-8 文本文件，再将文件路径传给程序 | 填 --prompt-file 等任务文件参数名；留空表示位置参数 |

表单中的“文本文件路径”即“通过文件传入任务”。用户不需要准备任务文件或填写具体路径。任务正文、文件名和文件路径均由平台在运行时提供。

例如选择 argv，任务参数名填 -p，平台会调用类似 agent-cli -p “完整任务文本”的入口。不要把“-p 接收任务文本”等自然语言填入参数名。

### 4.4 基座模型连接
基座模型是 Agent 在执行任务时调用的模型。普通用户在接入表单中选择已有模型资产，不重复填写服务地址、API Key 或请求模型标识，也不填写变量映射、配置模板或转换脚本。

所有新接入镜像必须支持以下三个标准环境变量。具体值由平台从所选模型资产获取，在运行时注入；镜像开发者不得把实际服务地址、请求模型标识或凭据写死在镜像中。

| 变量 | 平台提供的值 |
|---|---|
| OPENAI_BASE_URL | 所选模型资产的服务地址 |
| OPENAI_MODEL | 所选模型资产的请求模型标识 |
| OPENAI_API_KEY | 所选模型资产的凭据 |

镜像内的程序必须实际读取并使用这三个值，不能只声明变量名称，也不能被内置固定配置覆盖。如果原生 Agent 使用其他变量、配置文件或 --model 参数，镜像开发者必须在交付前完成转换，让镜像入口把标准变量传给原生程序。普通用户使用完成适配的镜像，不负责改脚本。

已有演示资产保留历史测试中经过验证的平台适配方式；这仅说明历史接入事实，不免除后续新接入镜像的标准变量要求。

接入验证必须确认 Agent 实际使用了所选资产的服务地址、请求模型标识和凭据。未按规范使用标准变量的镜像不能通过接入验证。当前 Demo 保存接入信息后标记为“待验证”；“校验信息”只检查表单，尚未执行镜像启动和模型连通测试。

### 4.5 注入文件申报
每行只填写“分类 + 具体文件路径”。分类下拉按以下四组排列，直接选定一个具体分类即可，不需要再填写作用范围或加载方式；这些由平台核验。没有文件注入需求时可不申报，不增加接入必填项。

| 分组 | 可选分类 | 如何区分 |
|---|---|---|
| 指令与约束 | 指令、规则 | 指令说明 Agent 应如何工作；规则约束特定目录、文件或操作，可能有触发条件 |
| 技能与命令 | 技能、命令 | 技能封装可调用的工作方法；命令是 Agent 原生支持的自定义命令 |
| 记忆与历史 | 长期记忆、会话历史、任务状态 | 长期记忆保存跨任务知识或偏好；会话历史保存先前对话；任务状态保存待办、进度或检查点 |
| 运行配置 | 配置文件 | Agent 明确支持的行为配置，不包含平台管理的模型凭据 |

路径示例包括项目指令 AGENTS.md、技能 .qwen/skills/support/SKILL.md、命令 .opencode/commands/review.md，以及 Deep Agents 用户长期记忆 HOME/.deepagents/agent/AGENTS.md。示例用于理解分类，不代表当前靶标已支持或核验了这些路径。文件名称不能单独决定分类：Deep Agents 的上述用户 AGENTS.md 用于长期记忆，其他 Agent 的同名文件可能用于项目指令，应按实际用途选择。

项目内使用相对路径，用户目录使用 HOME/ 前缀。填写具体文件，不填写目录、通配符、上级路径或包含占位符的模板。只申报 Agent 自身的控制、记忆或状态文件，不申报普通业务工作区文件。

文件存在不代表会被 Agent 加载；发现技能也不代表调用了技能正文。平台核验具体路径、作用范围、加载方式和触发条件后，才能将文件开放给任务选择。点击“校验信息”只检查格式；保存后状态为“待验证”，不等于已完成运行核验。沙箱准备由平台负责，不需要填写容器编排参数。

## 5. 准备与发布演练策略

在策略中心选择模型演练策略或 Agent 演练策略。先检查关联的攻击方法、题库或场景题库，再配置策略。

### 模型策略
配置攻击题库范围、攻击方法及参数、需要的辅助模型。方法详情中的模型名称带有用途前缀，例如“攻击生成模型”。需要蓝队时，在防护策略中查看对应配置。

### Agent 策略
选择场景题库与演练方法。基础安全演练用于观察任务自身的安全表现；间接提示注入可结合攻击生成模型，在指定注入文件中实施攻击。

间接提示注入的方法详情按“指令与约束、技能与命令、记忆与历史、运行配置”四组说明攻击面及文件示例。它描述方法可覆盖的类别，不表示任意靶标都已核验这些能力。接入和新建任务不提供普通业务工作区文件选项；已有记录中的工作区注入证据继续保留。

### 策略状态
| 状态 | 可执行操作 |
|---|---|
| 草稿 | 编辑、删除；点击策略名称继续编辑 |
| 已发布 | 查看详情、复制、删除；不能直接编辑，复制得到独立草稿后再修改 |

任务创建只选择已发布且未删除的策略。策略删除后不能用于新任务；已有草稿或待开始任务需要重新选择策略后才能启动，正在运行的任务继续使用已保存配置，历史详情与报告保留。策略、方法和题库详情统一在右侧抽屉查看；参数用表格展示。修改策略前可复制已有配置，避免改变历史任务所依赖的版本。

## 6. 创建演练任务

### 模型演练
1. 任务与对象：填写任务名称、可选描述，并选择靶标模型。
2. 红队配置：选择已发布攻击策略，检查题库范围、方法、参数与辅助模型。
3. 蓝队配置：选择是否启用；启用后选择输入、输出或“输入 + 输出”防护位置。
4. 评估配置：选择裁判模型，评估指标为攻击成功率（ASR）。
5. 执行配置：填写并发数和 Token 限制。并发数表示同时执行的攻防单元数量；Token 限制表示单次模型调用的最大输出长度。默认分别为 3 和 2048。
6. 确认配置：核对所有角色、范围及执行参数，保存任务。

### Agent 演练
1. 任务与对象：填写名称和描述，选择已接入智能体；按分类选择已核验的注入文件，可单选或多选。
2. 红队配置：选择已发布 Agent 演练策略，预览依次显示场景题库范围（题库名称与选取题数）、攻击方法；间接提示注入方法另显示攻击 Agent 基模。间接提示注入至少选择一个注入文件；基础安全演练不使用注入文件。
3. 评估配置：选择裁判模型。
4. 确认配置：核对靶标、策略、注入范围及裁判后保存。Agent 演练不配置蓝队。

切换 Agent 靶标会清空原有文件选择，避免把另一个资产的路径带入任务。

靶标模型、裁判模型、攻击生成模型及智能体基座模型的选择框底部均有“+ 去配置更多模型”。点击后前往平台模型管理，配置用途后点击“返回配置”对应入口继续原表单，已填写内容和当前步骤会保留。

“保存草稿”返回任务列表并记录当前配置步骤；“保存任务”进入待开始的任务详情，不自动运行。

## 7. 任务状态与演练详情

### 任务列表操作
点击草稿名称进入上次保存的配置步骤；其他任务名称进入详情。“更多”收纳复制配置、删除等操作，相同操作保持固定位置；草稿的编辑位于中间，与更多相邻。

| 状态 | 主要操作 | 补充操作 |
|---|---|---|
| 草稿 | 编辑 | 复制配置、删除 |
| 待开始 | 开始演练、详情 | 编辑配置、复制配置、删除 |
| 进行中 | 终止演练、详情 | 复制配置、删除 |
| 已完成 | 查看报告、详情 | 复制配置、删除 |
| 已终止或异常 | 详情 | 复制配置、删除 |

复制仅继承配置，副本始终为草稿，不继承进度、日志或结果。终止后的任务不会生成报告；需要重新测试时，复制配置创建新任务。

### 任务详情
任务信息摘要展示靶标、红队、裁判；模型任务另展示蓝队。“完整配置”抽屉可核对基础信息及详细配置。

演练进程包含画布、攻防明细和运行日志。画布展示进度、当前阶段内容及 ASR 圆环；攻防明细可选择单元查看相应内容；运行日志用于核对已记录的事件。

模型的轮次按攻击方法配置显示；攻破后结束该单元。Agent 暂不展示攻击轮次，任务目标中的步骤属于任务要求，不等于实际执行轨迹。

## 8. 阅读报告与导出证据

只有已完成任务提供演练报告。报告分为“结果分析”和“攻防明细”，上方可查看完整任务配置。

### 结果分析
模型报告包括演练结果、核心发现、攻击方法表现、场景风险、防护分析和下一步建议；有蓝队证据时才展示防护分析。

Agent 报告包括演练结果、核心发现、攻击方法表现、场景风险、靶标表现和下一步建议。靶标表现中的完成度表现与抵御表现均先给出整体分析，再按序号逐题列出完整判读内容，保留失误维度明细。方法表现从攻击者角度分析，不展示反推执行轨迹。

### 攻防明细与导出
按风险标签、判定结果等条件筛选，再打开单条详情核对题目、攻击内容、响应和判定依据。表格截断长文本时，详情保留完整内容。

模型与 Agent 的攻防明细列表都必须先勾选记录，“导出明细”按钮才会启用。清空勾选会重新禁用，不自动导出全部筛选结果。Agent 在按钮下拉中先选择一种内容，再选择格式：

| 内容 | 范围与格式 |
|---|---|
| 明细详情 | 已勾选记录；PDF 或 Markdown |
| 任务包 | 所选记录已有的对外产物源文件；ZIP |

单条详情的导出范围固定为当前记录。整份报告从页头“报告导出”选择结果分析、攻防明细或两者。PDF 导出会打开浏览器打印窗口，选择“另存为 PDF”。

### 结果口径
攻击成功率（ASR）= 攻破单元数 ÷ 有效判定单元数。异常与待完成不计入有效判定分母；没有有效判定时不把 ASR 当作 0%。

任务完成、文件生成、注入被读取或部分采纳，都不直接等于攻破。攻破结论以对应单元的判定及证据为准。

## 9. 模型评估与 Agent 评估

两个评估入口均位于对应演练报告下方，用于按靶标汇总浏览已完成任务结果。可以搜索靶标或策略、筛选风险等级，并在 ASR 表头切换排序。

模型评估提供靶标对比与蓝队对比。靶标对比应固定攻击策略、蓝队和裁判；蓝队对比应固定靶标、攻击策略和裁判。选择符合条件的任务后，查看结果差异。

Agent 评估展示智能体、ASR、风险等级、红队配置和裁判模型，并提供任务详情与报告入口。模型评估对应展示红队配置、蓝队配置和裁判模型。评估列表不展示完成时间；报告生成时间在演练报告列表查看。当前不提供独立的 Agent 对比操作。

比较结果前还应核对题集、参数、策略快照和注入范围。不同配置、不同样本量的 ASR 不应直接解释为整体能力排名。

## 10. 风险、通知与平台设置

### 风险中心
按来源、风险等级和处理状态筛选风险事件。“处理”菜单可标记忽略或已处理；需要再次验证时点击复测，核对复制后的配置再开始。

风险等级由平台规则决定，处理状态仅表示事件跟进情况，不会修改任务的原始判定结果。

### 消息通知
右上角消息提醒汇集任务开始、完成、报告和风险等事件。打开消息可进入相关内容，并区分已读与未读。

### 平台设置
右上角设置入口包含模型管理与风险管理。模型管理分配模型用途；风险管理调整触发条件、分级阈值及规则启停。分级阈值需要满足“触发值 < 中危下限 < 高危下限”。

## 11. 当前 Demo 的使用边界

当前 Demo 的创建、保存、复制、启动、终止和删除在页面会话内生效，刷新会清除新增操作并恢复初始数据；不提供撤销删除入口。

开始演练后使用已有任务证据进行演示回放。新选的靶标或注入范围会保存在配置中，但回放不是对这些配置重新执行的一次真实测试。前端填写校验也不等于容器运行验通。

使用本 Demo 评审交互和流程时，可在完整配置与明细中核对展示的配置和证据。
