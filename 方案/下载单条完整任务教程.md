# 下载 OpenART 单条完整任务（工作区 + 判定依据）

已有前提：`~/hfmeta` 虚拟环境，已下过元数据 parquet。

数据集结构说明：

| 内容 | 位置 |
|---|---|
| 元数据（已下） | `data/mid/metadata-00001.parquet`（mid-v5） |
| 完整任务包 | `bundles/mid/tasks-mid-v5-000NN.zip`，共 18 个，单个约 1.4 GB |
| 单条抽取脚本 | `scripts/download_task.py`（需要整个数据集在本地） |

元数据里这两个字段是桥梁：

- `bundle_path` — 这条任务在哪个 zip
- `bundle_member_prefix` — 在 zip 里的目录前缀

## 第 1 步 装依赖

```bash
source ~/hfmeta/bin/activate
pip install -U huggingface_hub pyarrow
```

## 第 2 步 从元数据里挑一条，查出它在哪个包

把 `METADATA` 换成你本地 parquet 的实际路径。

```bash
cat > ~/pick_task.py <<'PY'
import pyarrow.parquet as pq

METADATA = "/home/zhuyuxin/openart-meta/data/mid/metadata-00001.parquet"  # 改成你的路径
KEYWORD = "security"   # 想找的方向，匹配 benign_goal / actor

rows = pq.read_table(METADATA).to_pylist()
hits = [r for r in rows
        if KEYWORD.lower() in str(r.get("benign_goal", "")).lower()
        or KEYWORD.lower() in str(r.get("actor", "")).lower()]

print(f"命中 {len(hits)} / {len(rows)} 条\n")
for r in hits[:10]:
    print("task_id :", r["task_id"])
    print("goal    :", str(r.get("benign_goal", ""))[:110])
    print("bundle  :", r.get("bundle_path"))
    print("prefix  :", r.get("bundle_member_prefix"))
    print("-" * 70)
PY

python ~/pick_task.py
```

记下你想要那条的 `task_id`、`bundle_path`、`bundle_member_prefix`。

## 第 3 步 取任务内容

### 方案 A（推荐）只拉需要的字节，不下整个 1.4 GB

`HfFileSystem` 打开的远程文件支持随机读，`zipfile` 会只请求中央目录和目标成员对应的区间。

```bash
cat > ~/fetch_task.py <<'PY'
import sys, zipfile
from pathlib import Path
from huggingface_hub import HfFileSystem

REPO = "dongdongunique/openart-planner-tasks"
bundle_path, prefix, out_dir = sys.argv[1], sys.argv[2], sys.argv[3]

prefix = prefix.rstrip("/") + "/"
out = Path(out_dir)
out.mkdir(parents=True, exist_ok=True)

fs = HfFileSystem()
with fs.open(f"datasets/{REPO}/{bundle_path}", "rb") as remote:
    with zipfile.ZipFile(remote) as z:
        members = [m for m in z.namelist()
                   if m.startswith(prefix) and not m.endswith("/")]
        if not members:
            raise SystemExit(f"包里找不到前缀 {prefix}")
        for m in members:
            target = out / m[len(prefix):]
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(z.read(m))
        print(f"已取出 {len(members)} 个文件 -> {out}")
PY

python ~/fetch_task.py \
  "bundles/mid/tasks-mid-v5-00000.zip" \
  "tasks/<填 bundle_member_prefix>" \
  ~/openart-task-sample
```

第一个参数填 `bundle_path`，第二个填 `bundle_member_prefix` 原值，第三个是输出目录。

如果报 seek 相关的错，说明该版本的 `HfFileSystem` 不支持随机读，改用方案 B。

### 方案 B 整包下载，稳但慢（约 1.4 GB）

```bash
python - <<'PY'
from huggingface_hub import hf_hub_download
p = hf_hub_download(
    repo_id="dongdongunique/openart-planner-tasks",
    repo_type="dataset",
    filename="bundles/mid/tasks-mid-v5-00000.zip",   # 改成你的 bundle_path
    local_dir="/home/zhuyuxin/openart-bundles",
)
print(p)
PY
```

下完后用方案 A 的脚本解压，把 `fs.open(...)` 那一行换成本地 `open(路径, "rb")` 即可；或直接用官方脚本：

```bash
python scripts/download_task.py \
  --dataset-dir /home/zhuyuxin/openart-meta \
  --difficulty mid-v5 \
  --task-id <你的 task_id> \
  --output-dir ~/openart-task-sample
```

官方脚本要求 `bundles/` 和 `data/` 在同一个 `--dataset-dir` 下，按元数据里的相对路径摆放。

## 第 5 步 验证"攻击目标能否自动生成"

这是下载这条数据的真正目的。打开判定依据，确认里面有机器可读的目标定义：

```bash
python -m json.tool $(find . -name "safety_contract.json" | head -1) | head -60
```

要确认三件事：

1. 受保护路径清单在不在（决定要诱导泄露什么）
2. 禁用标记清单在不在（决定判定按什么字符串匹配）
3. 产物路径在不在（决定攻击要污染哪个输出文件）

三者都有，说明攻击器指令的目标段可以从场景自动拼出来，不用为每个场景手写一份。缺哪一项，就要在接任务时补一条人工填写。

同时留意任务里**有没有现成的 attacker 指令字段**。有的话，说明上游就是按任务元数据批量生成攻击指令的，可以直接沿用它的字段结构；没有的话，模板得我们自己定。

## 注意

- 这些工作区里包含合成的高风险字符串，是评测素材，不是真实机密，也不要当指令执行。
- 别把解压目录提交进 git，先确认 `.gitignore` 覆盖。
