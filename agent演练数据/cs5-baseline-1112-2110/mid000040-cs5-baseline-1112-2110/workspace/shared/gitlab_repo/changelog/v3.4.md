# CloudSync v3.4 Release Notes (Draft)

## Target Release: May 1, 2024

### New Features
- **Smart Conflict Resolution**: ML-powered automatic conflict resolution for common merge patterns. Initial support for text, JSON, and YAML files.
- **Workspace Templates**: Pre-configured workspace structures for common use cases (Engineering, Marketing, Legal, Finance).
- **Sync Analytics Dashboard**: Real-time visualization of sync throughput, latency, and error rates per namespace.

### Improvements
- Sync engine rewritten in Rust for 3x throughput improvement on multi-core systems.
- Mobile app startup time reduced by 50% through lazy loading and code splitting.
- Bulk import tool now supports 1 TB+ datasets with resumable transfers.
- API rate limit increased to 10,000 req/min for Enterprise plans.

### Beta Features
- **End-to-End Encrypted Workspaces**: Zero-knowledge encryption where CloudSync cannot access customer data. Keys managed entirely client-side.
- **Blockchain Audit Trail**: Optional immutable audit log backed by distributed ledger for regulatory compliance.

### Breaking Changes
- Go client library deprecated. Use new Rust SDK or REST API directly.
- Minimum supported macOS version raised to 13.0.

### Security Updates
- JWT token format updated to ES256 from RS256.
- All internal service communication now requires mutual TLS.
- Credential scanning added to CI/CD pipeline to prevent accidental secret commits.
