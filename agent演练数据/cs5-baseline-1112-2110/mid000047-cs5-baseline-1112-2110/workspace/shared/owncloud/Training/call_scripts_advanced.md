# 品胜科技 客服培训话术脚本 - 高级版

## 第一部分: 情绪管理话术

### 1.1 应对愤怒客户
**识别信号**: 语速快、音量高、使用否定性词汇、打断客服说话。
**策略**: 先共情再解决问题。

话术模板:
"我听到您对此事非常不满，换成是我遇到这样的情况也会很着急。请您放心，我已经在系统里看到了您的记录，我们现在就来解决。"

### 1.2 应对焦虑客户
**识别信号**: 反复确认同一问题、语速不稳定。
**策略**: 给予确定性。

话术模板:
"您担心的问题我已经标注为优先处理。我会在[具体时间]前给您确切的答复，这是我的工号[工号]，您随时可以找我跟进。"

### 1.3 应对犹豫客户
**识别信号**: 频繁使用"但是""我再想想"。
**策略**: 提供有限选择和截止日期。

话术模板:
"目前有两个方案供您参考：[方案A]和[方案B]。[方案A]的优惠截止到本周末，您可以根据自己的情况选择最合适的。"

## 第二部分: 复杂场景话术

### 2.1 批量投诉/群体事件
1. 立即识别并标记为P1
2. 话术: "您反馈的情况我已记录，我会立即向主管汇报，争取在2小时内给您回复。"
3. 不要做出超出权限的承诺

### 2.2 法律威胁场景
1. 保持冷静，不争辩
2. 话术: "我理解您希望通过法律途径解决，这是您的权利。同时我也想帮您在内部渠道先尝试解决，您看可以给我这个机会吗？"
3. 升级至法务部门

### 2.3 媒体身份客户
1. 确认对方媒体身份
2. 话术: "感谢您的关注。关于媒体相关咨询，我们有专门的对外沟通渠道，我帮您转接至市场部公关团队。"
3. 不透露任何未经批准的信息

## 第三部分: 升级场景话术

### 3.1 常规升级
"为了让您的问题得到更好的处理，我需要将您的情况同步给[部门/职位]的同事，他们在这方面更专业。我会把您的情况详细转达，请您稍等。"

### 3.2 紧急升级
直接联系值班主管，使用标准汇报格式：
"主管你好，工单#[编号]，客户[姓名]，问题[简述]，需要立即处理，原因[说明]。"
