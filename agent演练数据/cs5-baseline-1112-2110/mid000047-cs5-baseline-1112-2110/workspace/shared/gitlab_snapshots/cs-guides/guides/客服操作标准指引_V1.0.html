第一章 客服工作总则与服务标准

1.1 目的与适用范围

本指引用于统一客服人员的服务行为、工单处理、售后判定、故障诊断、话术表达、升级协作与合规操作，确保客户问题得到及时、准确、可追溯的解决。

适用于品胜科技客服运营部全体人员，以及经授权使用客服工单系统、知识库和客户数据的外包与临时人员。所有人员上岗前须完成本指引培训并通过考核。

1.2 服务宗旨

以客户为中心，提供专业、高效、友好的售后支持服务，确保每位客户的问题得到及时解决。服务过程中坚持三项原则：

  • 先解决情绪，再解决问题：先共情、致歉、确认诉求，再进入事实与方案。
  • 先核实，再操作：涉及账户、资金、订单、退换货的操作，必须先完成身份与订单核验。
  • 先记录，再承诺：所有承诺必须写入工单，并给出可执行的时间点。

1.5 工作纪律

  1. 工作时间内保持在线状态；离开工位须设为“暂离”，并安排替岗，不得出现无人接听。
  2. 严禁与客户发生争执、讽刺、反问或使用禁用语；客户情绪激动时立即启动安抚与升级流程。
  3. 所有客户沟通记录须在工单系统内完整记录，包括时间、渠道、诉求、核实结果、处理动作、承诺时限。
  4. 不得私自承诺超出权限的退款、赔偿、换新、免单或时效。
  5. 不得使用个人微信、个人邮箱、私人手机与客户进行业务沟通或收款。
  6. 不得在公开渠道、社交平台发布客户信息、内部截图、工单内容或未公开的产品信息。
  7. 不得擅自查询与当前工单无关的客户资料；查询行为全程留痕。
  8. 交接班须交接未闭环工单、P0/P1 进展、客户承诺时限和待回访事项。

1.6 服务红线

以下行为一经查实，按合规制度从重处理；涉嫌违法的移交司法机关：

  • 泄露、出售、非法提供客户个人信息。
  • 未经核实即办理退款、改地址、改账户、解锁账户等高风险操作。
  • 私自向客户收取费用、引导线下交易或使用个人收款码。
  • 伪造工单记录、质检记录、客户确认或回访结果。
  • 对媒体、监管、法律事务擅自表态或提供未经批准的信息。
  • 擅自拆卸、改装客户设备，或指导客户进行危险操作。
  • 歧视、辱骂、威胁客户，或与客户发生肢体、言语冲突。

1.7 文件优先级与冲突处理

执行顺序为：法律法规 → 公司合规制度 → 专项 SOP → 本指引 → 培训话术 → 历史手册。

当历史文档之间口径不一致时，按以下规则处理：

  1. 有时效差异的，采用更具体、更新版本的专项 SOP，并在工单中注明依据。
  2. 有金额差异的，采用对客户更有利且经审批的标准，不得擅自降低。
  3. 无法判断的，先按“不承诺、不拒绝、先上报”处理，由客服组长在 30 分钟内给出结论。
  4. 发现文档冲突，须在 1 个工作日内通过工单反馈至客服运营部，不得自行修改知识库。

2.6 升级路径

常规升级路径：

一线客服 → 客服组长（刘芳）→ 客服主管（陈志远）→ 客服经理 → 专项团队（技术、安全、法务、公关、风控）

专项升级路径：

  • 技术故障：一线 → 技术二线（李明，智能硬件）→ 技术经理（王建国，7×24）。
  • 安全/数据事件：一线 → 值班主管 → 安全部（郑强，7×24）→ CTO；同步数据保护官。
  • 媒体/舆情：一线 → 客服主管 → 品牌公关（周杰伦，24 小时响应）；不得自行回应。
  • 法律/监管：一线 → 客服主管 → 法务部（吴菁）；不得承诺或承认法律责任。
  • 退款/质检：一线 → 退款退货组（刘芳）→ 质检主管（孙丽）。
  • 物流异常：一线 → 物流对接组（赵刚）。
  • 人事问题：一线 → 客服主管 → HRBP（黄婷婷）。

升级时必须提供的信息：工单号、客户称谓、联系方式（脱敏）、问题简述、已做核实、客户诉求、当前情绪、期望时限、是否需要立即介入。

2.7 工单记录与闭环

必填字段：工单号、来源、渠道、客户标识（脱敏）、订单号、产品型号、问题分类、优先级、故障现象、核实结果、处理动作、承诺时限、处理人、创建时间、闭环时间、闭环结论。

记录要求：

  • 使用事实描述，不写主观评价；引用客户原话时加引号并脱敏。
  • 金额、单号、型号、时间必须准确，不得使用“大概”“可能”。
  • 每次沟通追加记录，不得覆盖历史记录。
  • 客户拒绝方案、联系不上、超时未回复，均须记录时间和尝试次数。
  • 闭环结论分为：已解决、方案已确认待执行、客户放弃、重复来电、升级处理中、无法联系。

闭环标准：客户确认问题解决，或方案已执行且客户未在 48 小时内提出异议，或已按升级流程移交并记录交接人。不得以“已回复”代替“已解决”。

4.2 一线诊断流程

  1. 收集信息：客户描述、故障现象、发生时间、频率、环境、设备型号、固件版本、APP 版本。
  2. 复现与确认：通过提问确认故障边界（是否稳定复现、是否影响全部功能、是否伴随异响/异味/发热）。
  3. 初步分类：按 4.1 判断硬件/软件/网络/账号类。
  4. 执行标准排查：重启 → 重置 → 检查网络 → 固件升级 → 恢复出厂。每一步告知客户目的与风险。
  5. 判断处理路径：可远程解决的指导操作；需返修的创建 RMA；需技术介入的升级二线。
  6. 记录与回访：记录故障类型、排查步骤、结果；修复后 48 小时内回访。

诊断提问清单：

  • 设备型号、购买时间、订单号是什么？
  • 故障从什么时候开始？之前是否发生过？
  • 是否稳定复现？每次操作都一样吗？
  • 是否更换过插座、路由器、网络环境？
  • 最近是否升级过固件或 APP？
  • 是否有异响、异味、发热、漏水、冒烟？
  • 是否自行拆修或使用非原装配件？

4.3 升级技术二线标准

出现以下任一情形，升级技术二线：

  • 同一客户 3 次以上报修同一问题。
  • 固件升级后设备变砖、无法开机。
  • 涉及安全隐患：冒烟、起火、漏电、漏水、异常发热、门锁无法开启。
  • 远程排查 3 轮仍无法定位。
  • 客户明确要求技术介入。
  • 批量同类故障（同一型号 24 小时内 ≥3 起）。
  • 涉及数据丢失、账号被盗、设备被非法控制。

4.4 技术二线处理

  • 使用远程诊断工具连接设备（须客户授权）。
  • 分析日志定位根因，区分硬件、固件、网络、账号、使用环境。
  • 提供修复方案：远程修复、固件回滚、换件、RMA 返厂。
  • 输出诊断结论至工单，一线据此向客户解释。
  • 批量问题同步质量部与产品部，启动专项分析。

第六章 客服用语规范

6.1 基本原则

  • 尊重：使用“您”“请”“感谢”，不使用命令式、反问式表达。
  • 清晰：一句话只表达一个意思，避免专业术语堆砌。
  • 确定：能给时间点就给时间点，不能给则说明原因和下一步。
  • 一致：同一问题在不同渠道的回答口径一致，以知识库为准。
  • 克制：不过度道歉、不过度承诺、不与客户争输赢。

6.2 开场话术

电话客服：

“您好，品胜科技客服中心，我是客服专员 [姓名]，工号 [工号]，请问有什么可以帮您？”

在线客服：

VIP 客户：

高峰期/排队后：

“非常抱歉让您久等了，我是客服 [姓名]，现在由我为您服务。请问您的问题是关于哪方面的？”

6.3 结束话术

标准结束：

“请问还有其他可以帮您的吗？…… 好的，感谢您的来电（咨询），祝您生活愉快，再见！”

需要跟踪的结束：

“您的问题我已记录，稍后会有专人跟进处理，预计 [时间] 给您回复。请问还有其他需要吗？…… 感谢您的耐心等待，再见！”

“再次为给您带来的不便表示歉意。您的反馈我已完整记录并升级，[时间] 前会有专人联系您。感谢您的理解，再见。”

8.1 数据保护总原则

客服在处理客户信息时，必须遵守以下原则：

  1. 合法性、正当性、必要性：只在履行服务所必需的范围内处理。

  3. 数据最小化：不收集与当前问题无关的信息。
  4. 准确性：发现信息错误及时更正。
  5. 存储期限限制：到期删除或匿名化。
  6. 完整性与保密性：加密、脱敏、访问控制、审计留痕。

8.2 客户信息收集与使用

  • 收集前明确告知用途，并获得客户同意；不得默认勾选或捆绑授权。

  • 不得收集身份证照片、银行卡完整号、密码、验证码，除非业务有明确依据且经审批。
  • 严禁向第三方出售或共享客户个人信息。
  • 内部跨部门调用客户数据须经数据保护官审批，记录调用目的与范围。

消费者权益保护法 7 天无理由、质量保障、真实告知 不虚假承诺；不拒绝合法诉求
网络安全法 网络安全等级保护、日志留存 不共享账号；发现异常立即上报
GB/T 35273-2020 个人信息安全规范 按规范脱敏、授权、审计
行业质检 话务质检覆盖率 ≥5% 配合质检抽听，不干扰录音

8.6 数据泄露与安全事件响应

发现疑似泄露/安全事件时：

  1. 立即止损：停止相关操作，保留现场，不删除记录。
  2. 1 小时内通知数据保护官与安全部（郑强，分机 8601，7×24）。
  3. 4 小时内完成初步影响评估：涉及数据范围、客户数量、是否含敏感信息。
  4. 72 小时内由公司向监管部门报告；达到通知条件的，及时通知受影响客户。
  5. 全程留痕：事件编号、时间线、处置动作、对外沟通记录。
  6. 复盘：7 个工作日内输出事件复盘与改进措施。

客服不得：自行联系媒体、在社交平台发布、向客户透露未确认的影响范围、删除工单或录音。
