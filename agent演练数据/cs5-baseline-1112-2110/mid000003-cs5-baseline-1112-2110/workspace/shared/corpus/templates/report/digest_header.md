# Client Correspondence Digest Template

## Purpose
Standardized format for compiling client email correspondence summaries across communication channels.

## Sections
1. **Overview**: High-level summary of the reporting period
2. **Key Decisions**: Decisions made during the period with responsible parties
3. **Action Items**: Outstanding tasks with owners and due dates
4. **Unresolved Questions**: Open items requiring follow-up
5. **Timeline**: Chronological list of all communications
6. **Participants**: All individuals involved in correspondence

## Guidelines
- Include only communications directly involving the client
- Cross-reference dates across email, Slack, and calendar events
- Mark items with clear status indicators: [OPEN], [IN PROGRESS], [RESOLVED]
- Attach supporting evidence file paths where applicable
