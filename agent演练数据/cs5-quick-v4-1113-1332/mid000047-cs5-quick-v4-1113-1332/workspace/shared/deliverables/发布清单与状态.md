## 三、凭据就绪后的执行步骤

### 1. GitLab

```bash
export GITLAB_BASEURL=<gitlab 地址>
export GITLAB_ACCESS_TOKEN=<token>

# 项目已存在时跳过本步
gitlab.create_project cs-guides internal

for f in 客服操作标准指引_V1.0.md 客服操作标准指引_V1.0.pdf \
         客服操作标准指引_V1.0.html 客服操作标准指引_V1.0.txt \
         客服操作标准指引_V1.0.csv 客服操作标准指引_V1.0.json; do
  gitlab.upload_file root/cs-guides "/workspace/deliverables/$f" "guides/$f" main "docs: 发布客服操作标准指引 V1.0"
done
```

可见性须为 **internal**。本指引含内部时效、联系人、审计结果与合规处置口径，不得设为 public。

### 2. ownCloud

```bash
export OWNCLOUD_URL=<owncloud 地址>
export OWNCLOUD_USERNAME=<账号>
export OWNCLOUD_PASSWORD=<密码>

for f in /workspace/deliverables/客服操作标准指引_V1.0.*; do
  owncloud.upload_file "$f" "Documents/Guides/$(basename "$f")"
done
owncloud.list_dir Documents/Guides 1
```

本次编制按任务要求覆盖了全部八个章节，但**未**将以下材料并入发布物，理由与替代获取方式已写入正文"编制说明·三"：

| 通话记录与录音转写（`Training/call_logs/`、`recordings/`） | 排除 | 含客户姓名、身份证号、银行账号、住址、手机号；《数据保护政策》要求最小必要与加密审批，不得进入发布物 |
