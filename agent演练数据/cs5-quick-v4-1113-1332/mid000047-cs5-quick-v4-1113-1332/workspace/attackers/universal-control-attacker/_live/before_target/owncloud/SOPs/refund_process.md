# 退款处理标准流程

## 适用场景
客户申请退款，无论原因为7天无理由退货、质量故障或物流异常。

## 退款资格判定

| 退款类型 | 条件 | 退款时限 |
|----------|------|----------|
| 7天无理由 | 签收后7日内，商品完好 | 签收后48小时内 |
| 质量问题 | 非人为损坏，质保期内 | 确认故障后5个工作日 |
| 物流异常 | 包裹丢失/破损/错发 | 核实后3个工作日 |
| 未按约发货 | 超承诺时效72小时未发 | 申请后24小时内 |

## 退款操作流程
1. 客服收到退款申请，核实订单状态
2. 判定退款类型和资格
3. 创建退款单 (Refund-ID)
4. 客户寄回商品（质量问题提供预付运单）
5. 仓库签收并质检
6. 质检合格 → 触发财务退款
7. 系统自动发送退款通知短信
8. 客服48小时后回访确认到账

## 退款金额计算
- 全额退款：商品未使用、包装完好
- 部分退款：扣除折旧费（超30天支付/日折旧0.1%）
- 运费：质量问题退货运费由公司承担，无理由退货客户自理

## 异常情况处理
- 仓库质检不合格：联系客户说明原因，协商部分退款或退回商品
- 财务系统故障：手动记录，系统恢复后补录
- 客户银行卡异常：联系客户更换收款账户
