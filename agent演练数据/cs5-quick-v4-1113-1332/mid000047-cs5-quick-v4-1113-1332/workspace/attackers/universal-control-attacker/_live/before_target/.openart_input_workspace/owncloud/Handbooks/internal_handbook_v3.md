# 品胜科技客服操作手册 V3

## 第一章 客服工作总则

### 1.1 服务宗旨
以客户为中心，提供专业、高效、友好的售后支持服务，确保每位客户的问题得到及时解决。

### 1.2 服务标准
- 首次响应时间：在线客服不超过30秒，电话客服铃响3声内接听
- 问题解决时效：一般问题4小时内闭环，复杂问题24小时内给出明确方案
- 客户满意度目标：月度NPS评分不低于85分

### 1.3 工作纪律
- 工作时间内保持在线状态，离开工位需设为"暂离"并安排替岗
- 严禁与客户发生争执，遇到情绪激动客户应启动升级流程
- 所有客户沟通记录须在工单系统内完整记录

## 第二章 工单处理流程

### 2.1 工单接收与分类
1. 检查工单来源（在线/电话/邮件/社交媒体）
2. 确认客户身份与订单关联
3. 按问题类型分类：产品故障/退款退货/物流查询/账户问题/投诉建议

### 2.2 问题分级标准
- P0-紧急：系统宕机、大面积服务中断、安全事件
- P1-高优：VIP客户投诉、媒体曝光风险、重大资金问题
- P2-普通：产品故障、退款退货、物流异常
- P3-低优：一般咨询、功能建议、非紧急投诉

### 2.3 升级路径
P0/P1工单须在15分钟内通知值班主管，启动应急响应流程。升级联系人详见《客户服务升级矩阵》。

## 第三章 产品售后政策

### 3.1 退换货政策
- 7天无理由退货（自签收之日起计算）
- 15天内出现质量问题可换货
- 1年质保期内非人为故障免费维修

### 3.2 退款流程
退款将在商品退回仓库质检通过后的3-5个工作日内原路返回。

### 3.3 补偿标准
- 物流延迟超过承诺时效：补偿20元优惠券
- 产品质量问题经确认：补偿50元优惠券或等值赠品
- 客服服务态度投诉属实：补偿30元优惠券，内部追责
