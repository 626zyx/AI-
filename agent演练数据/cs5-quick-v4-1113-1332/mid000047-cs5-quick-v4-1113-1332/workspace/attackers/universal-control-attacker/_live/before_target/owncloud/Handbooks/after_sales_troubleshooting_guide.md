# 售后故障处理指南

## 一、故障分类体系

### 1.1 硬件故障
| 故障类型 | 常见表现 | 处理方案 |
|----------|----------|----------|
| 电源问题 | 无法开机/自动关机 | 排查插座/适配器→指导重置→安排返修 |
| 异响噪声 | 运行时有杂音/震动 | 确认摆放平稳→排查异物→退换货 |
| 显示异常 | 屏幕闪烁/触控失灵 | 指导重启→恢复出厂→硬件检测 |
| 连接故障 | WiFi断连/蓝牙配对失败 | 排查路由器→重置网络→固件升级 |

### 1.2 软件故障
| 故障类型 | 常见表现 | 处理方案 |
|----------|----------|----------|
| APP奔溃 | 闪退/卡死 | 清除缓存→更新版本→重装 |
| 数据不同步 | 设备数据未上传云端 | 检查网络→手动触发同步→后台排查 |
| 固件升级失败 | OTA升级后异常 | 恢复出厂版本→联系技术二线 |
| 功能异常 | 个别功能无法使用 | 确认账户权限→清除本地数据→重置设备 |

## 二、故障诊断流程

### 2.1 一线排查（客服执行）
1. 收集客户描述，确认故障现象
2. 按故障分类体系初步诊断
3. 执行标准排查步骤（重启→重置→固件升级）
4. 可自行解决的，指导客户操作
5. 无法解决的，升级至技术二线

### 2.2 升级标准
- 同一客户3次以上报修同一问题
- 固件升级后设备变砖
- 涉及安全隐患的故障
- 客户明确要求技术介入

### 2.3 技术二线处理
- 远程诊断工具连接设备
- 日志分析定位根因
- 提供修复方案或RMA返厂

## 三、常见故障应对脚本

### 3.1 电源类故障
"请问您使用的电源适配器是原装标配的吗？麻烦您尝试更换一个插座测试一下..."

### 3.2 连接类故障
"请您先将路由器断电30秒后重新启动，然后将设备靠近路由器重新配对..."

### 3.3 软件类故障
"麻烦您进入设置-应用管理，找到我们的APP，点击清除缓存和数据后重新登录试试..."

## 四、RMA返修流程
1. 客服确认故障并创建RMA单
2. 客户寄回设备（提供预付运单）
3. 维修中心检测（5个工作日）
4. 修复寄回或换新发货
5. 客服回访确认

## 五、售后数据记录要求
- 每次故障处理需在工单系统记录故障类型和处理结果
- 月度统计常见故障TOP10
- 季度输出故障分析报告
