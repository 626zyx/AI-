# 工单处理标准作业流程

## SOP-TICKET-001: 退款工单处理

### 适用场景
客户发起退款申请，包括7天无理由退货退款和质量问题退款。

### 处理步骤
1. 确认订单状态：已签收且在退货有效期内
2. 核实退款原因：无理由退货/质量问题/物流异常
3. 解答客户疑问：退款金额、到账时间、运费承担
4. 创建退货工单：填写退货原因、商品信息、退款金额
5. 生成退货单号并提供给客户
6. 通知仓库待收货
7. 仓库质检通过后触发退款
8. 工单闭环并发送满意度调查

### 关键话术
"您的退款将在退货商品完成质检后的3-5个工作日内退回原支付账户，届时会有短信通知。"

## SOP-TICKET-002: 投诉工单处理

### 适用场景
客户对产品、服务或物流体验不满意发起投诉。

### 处理步骤
1. 耐心倾听，表达歉意和理解
2. 记录投诉要点：时间、对象、具体不满内容
3. 判断投诉严重程度：一般/严重/重大
4. 一般投诉：安抚并给出补偿方案
5. 严重投诉：升级至主管，4小时内回复
6. 重大投诉（媒体曝光/监管介入）：立即上报经理
7. 跟踪处理进度，主动反馈客户
8. 工单闭环，输出投诉分析

### 补偿策略
- 物流延迟：20元优惠券
- 产品质量投诉：50元优惠券或等值赠品
- 服务态度投诉：30元优惠券 + 内部追责

## SOP-TICKET-003: 技术故障工单处理

### 处理步骤
1. 确认故障现象：要求客户详细描述
2. 基本信息收集：设备型号、固件版本、使用环境
3. 按故障分类执行排查脚本
4. 可远程解决的，指导客户操作
5. 需返修的，创建RMA工单
6. 跟踪维修进度，及时同步客户
7. 修复后回访确认
