FACILITATOR QUICK NOTES — Tools Training Workshop

SETUP (15 min before):
- Open JIRA sandbox project in browser tab
- Open Confluence onboarding page in another tab
- Have GitHub test repo URL copied to clipboard
- Confirm Slack is logged in with /open available
- Test ownCloud connection

DURING WORKSHOP:
- Start with a quick round of "what tool questions do you already have?" (5 min)
- Demo each tool in order listed in the guide
- Pause after each section for questions — don't rush through all tools at once
- For the hands-on section, walk around if in-person or ask people to share screens if remote
- Budget extra time for GitHub SSH key setup — this always takes longer than expected

COMMON ISSUES SEEN IN PREVIOUS SESSIONS:
- JIRA sandbox project not visible for some roles — workaround: use JIRA test project
- ownCloud sync client blocked by corporate firewall — use web interface as fallback
- Zoom recording permission not granted for new accounts — request via IT service catalog
- GitHub 2FA not yet enabled — show the setup page URL

AFTER WORKSHOP:
- Send follow-up email with links to all tool documentation
- Share the recording (if made) within 24 hours
- Add any new issues to the tools FAQ
