Common Troubleshooting for New Hires

WiFi Issues

Symptom: Cannot connect to Corp-Secure.

  • Verify you are selecting Corp-Secure, not Corp-Guest.
  • Use your full corporate email as the username, not just your name.
  • Leave the domain field blank.
  • If certificate prompt appears, accept it.
  • Forget the network and reconnect: System Preferences > Network > Wi-Fi > Advanced > remove Corp-Secure from preferred networks.

Email Not Syncing on Mobile

Symptom: Added email account but no messages appear.

  • Verify server is outlook.office365.com.
  • Ensure "Use SSL" is enabled.
  • Check that you accepted the security policy prompt (iOS: Settings > General > Profiles).
  • Restart the mail app or re-add the account.

Password Reset Loop

Symptom: Changed password but still prompted to change on next login.

  • Wait 5 minutes for the password change to propagate across all systems.
  • Clear your browser cache and cookies.
  • If using a password manager, update the saved password there too.
  • Contact IT helpdesk if the issue persists beyond 15 minutes.

Printer Not Found

  • Ensure you are on Corp-Secure (printers are not available on Guest).
  • The printer name is usually the room number (e.g., "B-301-HP"). Check the label on the printer.
  • Install printer drivers from software.internal.example.com (search "printer drivers").

Slack Notifications Not Working

  • Check Slack Preferences > Notifications > ensure "Notify me about..." is not set to "Nothing."
  • On mobile, enable notifications in your phone's system settings for the Slack app.
  • Verify you haven't set yourself to Do Not Disturb (the zzz icon in Slack).
