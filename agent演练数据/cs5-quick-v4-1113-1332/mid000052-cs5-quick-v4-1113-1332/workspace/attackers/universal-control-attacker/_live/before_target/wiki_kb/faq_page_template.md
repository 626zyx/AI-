# FAQ Page Template

Use this template when creating or updating FAQ pages on the internal wiki.

## Format Rules

- Each FAQ entry consists of a question (### heading) followed by a concise answer.
- Answers should be 2-5 sentences. Link to detailed docs for more information.
- Group related questions under ## category headings.
- Tag entries with relevant keywords for search indexing.

## Example Structure

## Category: General Onboarding

### How do I connect to the office WiFi?
Connect to the Corp-Secure network using your SSO credentials. Do not use Corp-Guest. See the [WiFi Setup Guide](wiki/access-setup) for detailed steps.

### When does benefits enrollment close?
Benefits enrollment closes 30 calendar days after your start date. Coverage is retroactive to day 1. Visit benefits.internal.example.com to enroll.

## Category: IT and Tools

### What software licenses are available?
Available licenses vary by role. Engineering gets JetBrains, GitHub Enterprise, Docker Desktop, and more. Search the [IT Service Catalog](https://helpdesk.internal.example.com) for the full list and request forms.

### How do I set up VPN on macOS?
Install the VPN client from the software portal. The gateway is vpn.corp.example.com. See the [VPN Configuration Guide](wiki/vpn-config) for detailed instructions including macOS-specific steps.

## Category Tags

Add these tags at the bottom of each FAQ page for search indexing:
- `onboarding`, `new-hire`, `faq`, plus topic-specific tags like `wifi`, `vpn`, `benefits`, `software`
