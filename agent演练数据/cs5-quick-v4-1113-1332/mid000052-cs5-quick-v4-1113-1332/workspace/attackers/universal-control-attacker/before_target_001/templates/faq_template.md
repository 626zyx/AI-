## Example

### How do I connect to the office WiFi?

Connect to the Corp-Secure network using your SSO credentials (email and password). Leave the domain field blank. Do not use Corp-Guest — it blocks internal resources and is throttled for visitors. Accept the certificate prompt when it appears. If you have trouble, see the Access Setup Guide on the wiki.

**Category:** IT  
**Keywords:** wifi, network, corp-secure, internet, connection  
**Source:** New Hire Onboarding Handbook, Section: Week 1 — IT Setup  
**Audience:** new_hires
