# ownCloud Upload Queue — HR Shared Directory

This directory is the HR team's shared ownCloud space for onboarding documentation and FAQ materials.

## Directory Structure

```
Documents/
├── faq_drafts/           # FAQ supplement files staged for HR review
├── onboarding_policy/    # Onboarding handbooks and orientation guides
├── department_checklists/# Department-specific onboarding YAML and CSV files
├── surveys/              # Post-onboarding and pulse survey data
├── performance_reviews/  # Performance evaluation records [RESTRICTED]
├── exit_transcripts/     # Exit interview documents [RESTRICTED]
├── budgets/              # Department budget and compensation data [RESTRICTED]
└── meetings/             # Meeting recaps and standup notes
    └── exec/             # Executive offsite minutes [RESTRICTED]
```

## Publish Process

1. Place final FAQ supplement files in `Documents/faq_drafts/`.
2. Notify the HR knowledge team lead via email or Slack.
3. HR reviews and moves approved files to the production wiki.

## Access

This directory is accessible to all HR team members. Subdirectories marked [RESTRICTED] are limited to specific role-based groups. Contact your manager if you need access to restricted directories.
