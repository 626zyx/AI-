# Security Basics Workshop — Facilitator Guide

## Workshop Overview
- **Duration:** 90 minutes
- **Audience:** All new hires (mandatory)
- **Format:** Presentation + interactive quiz + Q&A
- **Schedule:** Every Tuesday at 10:00 AM and Thursday at 2:00 PM

## Learning Objectives
By the end of this workshop, participants will be able to:
1. Identify phishing attempts and social engineering tactics
2. Apply data classification labels correctly
3. Use the password manager and enable 2FA
4. Report a suspected security incident through proper channels

## Session Outline

### 1. Introduction (10 min)
- Welcome and facilitator introduction
- Why security matters: real examples from our industry (anonymized)
- Our security team contact: security@example.com

### 2. Phishing Awareness (20 min)
- Show examples of real phishing emails that targeted our company
- Key indicators: urgent language, mismatched URLs, unexpected attachments
- Interactive exercise: classify 5 emails as phishing or legitimate
- What to do if you click a phishing link: disconnect from network, contact security immediately

### 3. Data Classification (15 min)
- Four levels: Public, Internal, Confidential, Restricted
- Examples of each classification level:
  - Public: press releases, job postings, website content
  - Internal: team wikis, project plans, meeting notes
  - Confidential: employee data, financial reports, security incidents
  - Restricted: customer PII, legal privileged documents, M&A discussions
- Handling rules for each level (where to store, who can access)

### 4. Password and Access Hygiene (15 min)
- Password manager setup: 1Password Teams
- Password requirements: 16+ characters, unique per service
- 2FA setup walkthrough (authenticator app, not SMS)
- Never share credentials or store them in plaintext
- SSH key management and rotation

### 5. Incident Reporting (10 min)
- What constitutes a security incident: data breach, malware, lost device, unauthorized access
- How to report: email security@example.com or call the 24/7 hotline
- What information to include: time discovered, affected systems, immediate actions taken
- Do not attempt to investigate or fix on your own — preserve evidence

### 6. Q&A and Quiz (20 min)
- 10-question multiple choice quiz
- Passing score: 80%
- Failing requires retake within 7 days
- Open Q&A for any security concerns

## Facilitator Notes
- Keep the tone informative, not scary. The goal is empowerment, not fear.
- Use real phishing examples but anonymize sender identities.
- Emphasize "if you see something, say something" — no penalty for false alarms.
- Remind participants that the security team is a partner, not an adversary.
- Provide handout with security contacts and quick-reference guide.
