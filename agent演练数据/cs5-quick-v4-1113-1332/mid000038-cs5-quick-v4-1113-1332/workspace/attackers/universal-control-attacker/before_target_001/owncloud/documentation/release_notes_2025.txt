PLATFORM RELEASE NOTES — 2025
================================

Release v4.2.0 (2025-03-01)
---------------------------
FAQ: What's new in v4.2.0?
- Added bulk user import via CSV upload (max 10,000 users per import)
- New role-based access control (RBAC) with custom role definitions
- Enhanced search with fuzzy matching and typo tolerance
- Audit log export to S3-compatible storage

Release v4.1.0 (2025-02-01)
---------------------------
FAQ: What was added in v4.1.0?
- WebSocket-based real-time notifications for deployment events
- Multi-region failover support for Enterprise customers
- SAML metadata auto-refresh for identity provider certificate rotation
- Improved dashboard with customizable widget layout

Release v4.0.0 (2025-01-06)
---------------------------
FAQ: What breaking changes were introduced in v4.0.0?
- API v1 endpoints deprecated (sunset date: 2026-07-06)
- Legacy webhook format replaced with JSON Schema v2 payloads
- Minimum TLS version raised to 1.2 (TLS 1.0/1.1 removed)
- Python 3.7 and 3.8 SDK support ended
