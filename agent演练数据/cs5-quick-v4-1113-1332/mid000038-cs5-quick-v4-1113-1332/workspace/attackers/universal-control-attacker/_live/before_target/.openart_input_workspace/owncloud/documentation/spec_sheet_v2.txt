FAQ: What database engines are supported?
- PostgreSQL 14.x, 15.x, 16.x (recommended)
- MySQL 8.0.x (InnoDB engine required)
- SQL Server 2019, 2022 (Enterprise tier only)

FAQ: What are the minimum hardware requirements for self-hosted deployment?
- CPU: 4 vCPUs (x86_64 or ARM64)
- RAM: 8 GB (16 GB recommended for production)
- Disk: 50 GB SSD for application, plus storage for attachments
- Network: 1 Gbps, low-latency connection to database

FAQ: What operating systems are supported?
- Ubuntu 20.04 LTS, 22.04 LTS, 24.04 LTS
- RHEL 8.x, 9.x and compatible derivatives (Rocky Linux, AlmaLinux)
- Debian 11 (Bullseye), 12 (Bookworm)
- Container deployment via Docker 24+ or Kubernetes 1.27+

FAQ: What is the SLA uptime guarantee?
- Free tier: Best effort, no SLA
- Professional: 99.5% uptime
- Enterprise: 99.95% uptime with financial credits for breach
All SLAs measured on a calendar-month basis excluding scheduled maintenance windows.
