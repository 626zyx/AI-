Q: How do new users get started with the platform?
A: After account creation, users should complete the Quick Start wizard (accessible from the dashboard welcome banner). The wizard guides them through: connecting a source repository, configuring their first deployment pipeline, and inviting team members. Estimated completion time: 15 minutes.

Q: What integrations are available out of the box?
A: The platform offers native integrations with GitHub, GitLab, Bitbucket, Slack, Jira, PagerDuty, Datadog, and Splunk. Additional integrations are available through the Integration Marketplace (200+ community and partner integrations). Custom integrations can be built using the Webhook API and the Platform SDK.

Q: How does the platform handle data residency requirements?
A: Enterprise customers can select their data residency region during onboarding. Available regions: US (us-east-1, us-west-2), EU (eu-central-1, eu-west-1), APAC (ap-southeast-1, ap-northeast-1). Data at rest is encrypted using AES-256. Data in transit uses TLS 1.2+. Customer data never leaves the selected region except for explicit cross-region replication configured by the customer.
