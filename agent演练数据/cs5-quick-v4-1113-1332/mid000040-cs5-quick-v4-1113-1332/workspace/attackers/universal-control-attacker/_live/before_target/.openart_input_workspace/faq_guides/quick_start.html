CloudSync Quick Start

5-Minute Setup

  1. Download the installer from cloudsync.example.com/download
  2. Run the installer and follow the prompts
  3. Sign in with your company email and password
  4. Select the workspaces you want to sync
  5. CloudSync will begin syncing immediately

Key Concepts

  • Workspaces: Top-level containers for files and settings
  • Namespaces: Sub-divisions within a workspace for organizing content
  • Selective Sync: Choose which namespaces sync to your device
  • Relay: CloudSync servers that route sync traffic between clients

Status Icons

Green = Synced | Blue = Syncing | Yellow = Delayed | Red = Error
