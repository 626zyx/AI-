# CloudSync Onboarding Guide for New Team Members

## Welcome to CloudSync!

This guide will help you get started with CloudSync in your first week. Follow these steps in order for the smoothest onboarding experience.

### Day 1: Account Setup
1. Check your email for the CloudSync invitation from your team admin
2. Click "Accept Invitation" and create your account password
3. Set up multi-factor authentication (MFA) - this is required for all accounts
4. Download the CloudSync desktop client for your operating system
5. Sign in to the desktop client using your new credentials

### Day 2: Understanding Your Workspace
1. Review the workspace structure your admin has set up
2. Identify which namespaces you have access to (visible in the left sidebar)
3. Understand the sync status indicators:
   - Green checkmark: Fully synced
   - Blue arrows: Sync in progress
   - Yellow warning: Sync delayed
   - Red X: Sync error
4. Test creating a file in a shared namespace and verify it appears for a teammate

### Day 3: Selective Sync Configuration
1. Open Settings > Selective Sync
2. Review which directories are included in your sync policy
3. Exclude large directories you don't need locally (e.g., archive/, media/)
4. Set up any team-specific sync rules your manager recommends
5. Understand that excluded files are still available on-demand via the web interface

### Day 4: Collaboration Features
1. Learn about file locking: right-click any file > Lock to prevent concurrent edits
2. Test the conflict resolution: edit the same file as a teammate simultaneously
3. Explore the version history: right-click > Version History to see all revisions
4. Set up comment notifications for files you collaborate on frequently

### Day 5: Advanced Tips
1. Keyboard shortcuts: Ctrl+Shift+S (Windows/Linux) or Cmd+Shift+S (Mac) for quick sync status
2. Configure bandwidth limits in Settings > Network if you're on a metered connection
3. Set up the mobile app for access on the go
4. Bookmark the CloudSync Help Center for future reference

## Common Questions from New Users

**Q: My files aren't syncing. What should I check?**
A: First, check your internet connection. Then check if the CloudSync agent is running (look for the tray icon). If both are fine, try restarting the agent.

**Q: Can I access files when I'm offline?**
A: Yes! Files that were synced before going offline remain accessible. Changes made offline will sync automatically when you reconnect.

**Q: How do I share files with external partners?**
A: Use the Share Link feature. Right-click any file > Share > Create Link. You can set expiration dates and password protection.
