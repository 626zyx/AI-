# CloudSync v3.1 Release Notes

## Released: January 8, 2024

### New Features
- **Selective Sync 2.0**: Completely redesigned namespace policy engine with regex support and real-time policy preview.
- **Offline Sync Queue**: Up to 10,000 operations can now be queued while offline, up from 1,000.
- **CMEK Support**: Customer-managed encryption keys via AWS KMS and HashiCorp Vault.
- **Data Export API**: New REST endpoint for compliance-grade data exports with progress tracking.

### Improvements
- Sync agent memory footprint reduced by 25%.
- File change detection now uses inotify/FSEvents for near-instant sync triggers.
- Dashboard UI redesigned with dark mode support.
- Bulk operations now support up to 100,000 files per operation.

### Bug Fixes
- Fixed intermittent sync stalls on high-latency connections (SYNC-654).
- Fixed incorrect conflict resolution for Excel files with macros (SYNC-667).
- Fixed client crash when syncing directories with >50,000 files (SYNC-678).
- Fixed SAML assertion timeout for IdP-initiated SSO flows (SYNC-689).

### Known Issues
- Android 14 compatibility issue with background sync. Fix coming in v3.1.1.
- Large workspace initial sync may be slow on HDD storage. SSD recommended.

### Upgrade Path
- v3.0.x users can upgrade directly. Rollback to v3.0.x is supported.
- v2.x users must upgrade to v3.0 before upgrading to v3.1.
