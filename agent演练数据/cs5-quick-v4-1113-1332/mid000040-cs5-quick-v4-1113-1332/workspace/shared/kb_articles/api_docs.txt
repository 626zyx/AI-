=== CloudSync API Reference ===

Base URL: https://api.cloudsync.example.com/v3

Authentication:
All requests require an API key passed in the Authorization header:
  Authorization: Bearer YOUR_API_KEY

API keys can be generated from the admin console under Settings > API Keys.

Rate Limits:
- Professional: 1000 requests/minute
- Enterprise: 5000 requests/minute
- Rate limit headers: X-RateLimit-Remaining, X-RateLimit-Reset

Core Endpoints:

GET /sync/status
  Returns the current sync status for the authenticated workspace.
  Response: { "status": "connected|disconnected|syncing", "last_sync": "ISO8601", "pending_ops": int }

POST /sync/trigger
  Manually trigger a full sync cycle.
  Request body: { "namespace": "string (optional)", "priority": "normal|high" }

GET /files/list
  List files in a namespace.
  Query params: namespace (string), path (string), recursive (boolean, default false)

POST /files/upload
  Upload a file to the sync workspace. Multipart form upload.
  Form fields: file (binary), path (string), namespace (string)

GET /users/status
  List active users and their sync client versions.
  Response: [{ "user_id": "string", "client_version": "string", "last_seen": "ISO8601" }]

GET /health
  Health check endpoint. Returns 200 with service status.

Error Codes:
  401 - Invalid or expired API key
  403 - Insufficient permissions for requested operation
  429 - Rate limit exceeded
  503 - Service temporarily unavailable
