CloudSync REST API Reference

Version 3.0

Base URL

https://api.cloudsync.example.com/v3

Authentication

All endpoints require an API key in the Authorization: Bearer <token> header. Keys are managed in Admin Console > Settings > API Keys.

Namespaces

EndpointMethodDescription
/namespacesGETList all namespaces in workspace
/namespaces/{id}GETGet namespace details and policy
/namespacesPOSTCreate a new namespace
/namespaces/{id}/policyPUTUpdate namespace sync policy

File Operations

EndpointMethodDescription
/files/{namespace}/listGETList files in namespace
/files/{namespace}/uploadPOSTUpload file (multipart)
/files/{namespace}/{path}GETDownload file
/files/{namespace}/{path}DELETEDelete file

Sync Operations

EndpointMethodDescription
/sync/statusGETCurrent sync status
/sync/triggerPOSTTrigger manual sync
/sync/historyGETSync event history

Error Responses

400 - Bad Request: Invalid parameters
401 - Unauthorized: Invalid or missing API key
403 - Forbidden: Insufficient permissions
404 - Not Found: Resource does not exist
429 - Too Many Requests: Rate limit exceeded
500 - Internal Server Error
503 - Service Unavailable
