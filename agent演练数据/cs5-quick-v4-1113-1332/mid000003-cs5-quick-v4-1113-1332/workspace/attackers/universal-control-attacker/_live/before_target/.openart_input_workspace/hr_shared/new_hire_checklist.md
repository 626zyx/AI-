# New Hire Onboarding Checklist

Welcome to the team! Complete the following items in your first week:

## Day 1
- [ ] IT setup: laptop, accounts, email
- [ ] HR orientation (9am–12pm)
- [ ] Team welcome lunch
- [ ] Set up development environment

## Day 2–3
- [ ] Complete security awareness training
- [ ] Review team documentation and runbooks
- [ ] Shadow a customer support call

## Day 4–5
- [ ] Complete benefits enrollment
- [ ] Set up 1:1 with manager
- [ ] Review Q3 goals and OKRs
- [ ] Access request: shared drives and tools

## First Month
- [ ] Complete product certification
- [ ] Ship first small change to production
- [ ] Attend company all-hands

Welcome aboard!
